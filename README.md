# Remove Schema

Remove all Schema Markup / Structured data (Microdata, RDFa and/or JSON-ld) that you don’t want on your site.

## Requirements

- WordPress `6.8+`
- PHP `8.2+`
- Node.js `20+`
- npm `10+`
- Composer `2+`

## Quick Start

```bash
composer install
npm install
npm run build
```

The plugin entrypoint is `remove-schema.php`. Runtime services live in `src/`.
